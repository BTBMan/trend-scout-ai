# 项目身份：TrendScout AI (趋势星探)

我们正在为 Solana 黑客松构建一个“病毒指数盖戳”工具。
**目标：** 创建一个单页 DApp，允许用户检查加密趋势的病毒传播潜力，并将他们的发现“盖戳”上链。

# 核心用户流程

1. **输入 (Input):** 用户粘贴 Trends.fun 或 Twitter 的 URL。
2. **分析 (Analyze):** AI 分析内容并返回“病毒指数” (0-100) + “风险标签”。
3. **行动 (Action):** 用户点击“盖戳 (Stamp Alpha)”。
4. **上链 (On-Chain):** 应用调用 Solana Anchor 合约，将 [用户 + URL + 分数] 保存到 PDA 账户中。
5. **结果 (Result):** 用户看到“盖戳成功”的确认，并生成一张可分享的卡片。

# 生存法则 (至关重要)

1. **拒绝 Rust 复杂化：** 智能合约逻辑必须保持绝对的极简 (仅用于存储数据)。
